# 요구사항 정의서

## 프로젝트명

Job Skill Radar: 채용공고 분석 기반 데이터 직무 역량 추천 서비스

## 문제 정의

데이터 직무를 준비하는 학습자는 어떤 기술을 먼저 공부해야 할지 판단하기 어렵다. 채용공고에는 실제 시장이 요구하는 기술, 경력, 학력, 지역 정보가 담겨 있으므로 이를 분석하면 학습 우선순위를 더 현실적으로 정할 수 있다.

## 목표

- 데이터 직무 채용공고를 수집한다.
- 공고에서 기술스택을 추출하고 직무별 트렌드를 분석한다.
- 신입/경력, 지역, 직무별 요구사항 차이를 시각화한다.
- 사용자의 보유 기술과 목표 직무를 입력받아 부족한 역량을 추천한다.

## 주요 사용자

- 싸피 데이터트랙 지원자
- 데이터 분석/엔지니어링 직무 취업 준비생
- 채용시장 트렌드를 확인하려는 학습자

## 사용자 시나리오

1. 사용자는 목표 직무를 선택한다.
2. 사용자는 현재 보유 기술을 입력한다.
3. 서비스는 해당 직무 공고에서 자주 등장하는 기술스택을 보여준다.
4. 서비스는 사용자가 아직 보유하지 않은 기술을 우선순위로 추천한다.
5. 사용자는 추천 결과를 기반으로 학습 계획을 세운다.

## 기능 요구사항

| ID | 기능 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| FR-001 | 채용공고 수집 | 고용24 Open API에서 채용공고 목록을 수집한다. | 상 |
| FR-002 | 샘플 데이터 실행 | API 키가 없어도 샘플 데이터로 전체 흐름을 실행한다. | 상 |
| FR-003 | 데이터 정제 | 지역, 경력, 날짜, 급여, 직무명을 표준화한다. | 상 |
| FR-004 | 기술스택 추출 | 제목/본문에서 Python, SQL 등 기술 키워드를 추출한다. | 상 |
| FR-005 | 직무 분류 | 공고 제목과 기술 키워드로 데이터 직무 유형을 분류한다. | 중 |
| FR-006 | 트렌드 분석 | 직무별/경력별/지역별 채용 트렌드를 집계한다. | 상 |
| FR-007 | 역량 추천 | 목표 직무와 보유 기술을 바탕으로 부족한 기술을 추천한다. | 상 |
| FR-008 | 대시보드 | Streamlit으로 분석 결과를 시각화한다. | 상 |
| FR-009 | DB 저장 | 수집한 공고와 분석 결과를 SQLite에 저장한다. | 중 |
| FR-010 | 배포 | Streamlit Community Cloud 또는 Render에 배포한다. | 중 |

## 비기능 요구사항

| ID | 항목 | 설명 |
| --- | --- | --- |
| NFR-001 | 재현성 | API 키가 없어도 샘플 데이터로 결과를 재현할 수 있어야 한다. |
| NFR-002 | 확장성 | 추후 사람인/원티드 등 다른 데이터 소스를 추가할 수 있어야 한다. |
| NFR-003 | 유지보수성 | 수집, 정제, 분석, 추천 로직을 모듈로 분리한다. |
| NFR-004 | 개인정보 | 개인 식별 정보는 수집하지 않는다. |
| NFR-005 | 안정성 | API 오류 시 샘플 데이터 또는 이전 저장 데이터를 사용할 수 있어야 한다. |

## MVP 범위

- 데이터 직무 관련 샘플 공고 12건 이상
- 고용24 API 수집 스크립트
- 기술스택 빈도 분석
- 목표 직무별 추천
- Streamlit 대시보드

## 제외 범위

- 무단 웹 크롤링
- 개인회원 로그인 기반 데이터 수집
- 실제 합격 확률 예측
- 기업 평판 자동 평가
